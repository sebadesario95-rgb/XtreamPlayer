XTREAM PLAYER - CREAZIONE AUTOMATICA APK

Questo pacchetto e' gia' predisposto per GitHub Actions.
Non serve installare Android Studio sul PC per compilare l'APK.

PROCEDURA SEMPLICE:

1) Vai su GitHub e crea un nuovo repository vuoto.
2) Apri il repository e scegli "Add file" -> "Upload files".
3) Trascina TUTTO il contenuto di questa cartella nel riquadro di upload,
   compresa la cartella nascosta .github.
4) Premi "Commit changes".
5) GitHub avviera' automaticamente la compilazione.

PER SCARICARE L'APK:
- Apri la scheda "Actions" del repository.
- Entra in "Build Xtream Player APK".
- Apri l'ultima esecuzione completata con il simbolo verde.
- In fondo alla pagina trovi "Artifacts".
- Scarica "XtreamPlayer-APK".
- Dentro lo ZIP trovi app-debug.apk.

NOTA:
L'app e' un client per server Xtream Codes a cui hai diritto di accesso.
L'app non fornisce server, credenziali o contenuti.
